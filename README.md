# Credit-Card-Fraud-Detection---Gradient-Boosting-Classifier---Unbalanced-Classes

Решение задачи **бинарной классификации мошеннических транзакций** на сильно несбалансированном датасете. Основной упор сделан на сравнении бустинговых моделей (CatBoost и XGBoost) с моделью случайного леса, на работе с метриками классификации при дисбалансе и разборе теории градиентного бустинга.

## Датасет

[Credit Card Fraud Detection (Kaggle)](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)

**Признаки:**

| Признак | Описание |
|---|---|
| `Time` | время в секундах с первой транзакции |
| `V1`–`V28` | 28 анонимизированных признаков (главные компоненты PCA) |
| `Amount` | сумма транзакции |
| `Class` | целевая переменная: `0` — норма, `1` — фрод |

## Цель проекта

1. **Сравнение бустинговых моделей** — обучение и сопоставление двух реализаций градиентного бустинга (XGBoost и CatBoost) относительно бейзлайна (Random Forest).
2. **Метрики классификации** — precision, recall, F1 и ROC-AUC с построением ROC-кривых.
3. **Теоретическая база:**
   - **механика градиентного бустинга** — градиентный спуск в пространстве функций: как деревья обучаются на антиградиенте функции потерь;
   - **борьба с дисбалансом классов** — веса классов `class_weight`, техники семплирования (SMOTE, undersampling).

## Pipeline

**1. EDA и очистка:** анализ распределений, корреляций признаков с целевой переменной, удаление 1081 дубликата, визуализация дисбаланса и распределений ключевых V-компонент по классам.

**2. Подготовка данных:** стратифицированное разделение на train/test (сохранение доли фрода в обеих выборках).

**3. Обучение моделей:** Random Forest (baseline), XGBoost, CatBoost.

**4. Борьба с дисбалансом:** три подхода — веса классов, oversampling (SMOTE), undersampling (RandomUnderSampler) — с обучением всех моделей на каждом и сравнением метрик.

## Результаты

Метрики на тестовой выборке по трём методам борьбы с дисбалансом:

| Метод | Модель | Precision | Recall | F1 | ROC-AUC |
|---|---|---|---|---|---|
| **Веса классов** | Random Forest | 0.91 | 0.77 | 0.83 | 0.95 |
| **Веса классов** | XGBoost | 0.90 | 0.78 | 0.83 | 0.97 |
| **Веса классов** | CatBoost | 0.81 | 0.82 | 0.82 | 0.97 |
| **SMOTE** | Random Forest | 0.90 | 0.79 | **0.84** | 0.98 |
| **SMOTE** | XGBoost | 0.83 | 0.80 | 0.81 | 0.97 |
| **SMOTE** | CatBoost | 0.71 | 0.82 | 0.76 | 0.97 |
| **Undersampling** | Random Forest | 0.05 | 0.88 | 0.10 | 0.97 |
| **Undersampling** | XGBoost | 0.04 | 0.90 | 0.07 | 0.97 |
| **Undersampling** | CatBoost | 0.06 | 0.88 | 0.11 | 0.98 |

## Ключевые выводы

- **ROC-AUC обманчив при дисбалансе.** У всех девяти вариантов ROC-AUC = 0.95–0.98, по нему модели неотличимы. Но провальный undersampling (precision 4–6%) имеет тот же AUC 0.97, что и лучший Random Forest + SMOTE (precision 0.90). Вывод: на несбалансированных данных выбирать модель нужно по **precision / recall**, а не по ROC-AUC.

- **Семплирование управляет компромиссом precision/recall**, а не улучшает модель в целом: выравнивание классов смещает модель к поимке редкого класса (recall растет) ценой ложных срабатываний (precision падает).

- **Undersampling проваливается** — выбросив ~99.8% данных о норме, модель ловит почти весь фрод (recall 0.88–0.90), но precision рушится до 4–6% (95% тревог ложные).

- **SMOTE и веса классов работают** — сохраняют высокий precision при приемлемом recall. Лучший результат: **Random Forest + SMOTE** (F-мера = 0.84) и метод весов для XGBoost / Random Forest.

- **Веса классов — безопасный выбор по умолчанию:** не искажают данные, не создают синтетических артефактов и риска утечки, дают лучший precision.
